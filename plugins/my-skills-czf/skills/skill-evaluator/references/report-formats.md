# 报告契约

## 单 Skill

```markdown
## Skill 评估报告
**对象**：<Skill 名称/规范化路径>
**模式**：<单 Skill 静态评估 / 多 Skill 对比 / 多评审者交叉验证>
### <名称>
**综合得分：X.X / 10（等级 X）**
| 维度 | 分数 | 证据与说明 |
|---|---:|---|
| D1-D8 | X/10 | <具体文件/章节/行号> |
### 问题与建议
1. **<维度>**：问题；影响；建议；验收信号。
### 范围与未验证项
<实际读取/运行范围，以及仍缺少的证据>
### 下一步
<发布、修复、补测或等待输入；阻塞时只写解除阻塞所需条件>
```

## 多 Skill 对比

在每个单 Skill 报告后追加：并列 D1-D8 表（每个维度单独一行）、各自强弱、共同规律、从高到低排名。所有对象必须使用同一量表和权重。

## 多评审者

追加“独立评估结果”“显著分歧（差值 >=2）”“最终仲裁”。最终仲裁表至少包含：维度、最终分数、共识度、证据依据。没有实际运行的模型必须标为缺失，不得伪造结果。
